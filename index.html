Transformer-based End-to-End ML System (Research → Deployment → Production)

📌 Project Overview

This project extends a basic Transformer model into a production-ready forecasting system. It integrates deployment, real-time inference, interpretability, and robustness testing.

  • 📊 Time-series forecasting using Transformer
  • 🚀 ONNX + CoreML deployment
  • ⚡ Real-time streaming inference
  • 🔍 Explainability using attention & saliency
  • 🛡 Robustness under noise & adversarial attacks

🚀 Task 1: Deployment (ONNX + CoreML)

Problem

Model cannot run outside PyTorch environment.

Challenges

  • ONNX export failed (missing onnxscript)
  • Opset mismatch (LayerNormalization error)
  • CoreML requires static input shapes

Solution

  • Installed ONNX dependencies
  • Used opset ≥ 18
  • Fixed input shape (1, 24, 3)

Results

ONNX vs PyTorch diff: 2e-07 (numerically identical)

CoreML inference: ultra-fast

Insight

Deployment requires handling framework constraints beyond model training.

🔍 Task 2: Explainability

Problem

Transformer behaves as a black-box model.

Challenges

  • Attention weights not accessible
  • Visualization issues in terminal

Solution

  • Modified model to store attention weights
  • Used Plotly + HTML visualization
  • Implemented saliency maps

Visualization

Observations

  • Diagonal attention → accurate predictions
  • Scattered attention → poor predictions
  • Average attention distance ≈ 11 timesteps

Insight

Model learns meaningful temporal dependencies, validating its decision process.

⚡ Task 3: Streaming Inference

Problem

Model designed for batch inference, not real-time systems.

Challenges

  • Input shape mismatch
  • Limited dataset
  • Memory growth over time

Solution

  • Expanded input dimensions
  • Simulated streaming data
  • Implemented circular buffer

Results

Latency: 0.43 ms

Throughput: 2300 predictions/sec

Insight

Efficient memory and low latency are essential for real-time ML systems.
